# Sistema de Controle de Veículos e Disponibilidade

Projeto desenvolvido para a disciplina de Estruturas de Dados e Linguagem de Programação.

## Objetivo

Desenvolver um sistema para controle de veículos de uma locadora,
permitindo cadastro, consulta, reservas, controle de disponibilidade,
quilometragem, manutenção e histórico de aluguéis.

## Funcionalidades principais

- Cadastro de veículos
- Controle de disponibilidade
- Controle de reservas
- Bloqueio para manutenção
- Registro de quilometragem
- Histórico de aluguéis
- Pesquisa e ordenação da frota
- Identificação de veículos que necessitam manutenção

## Tecnologias

- Java
- Figma
- Jira
- UML
- Git/GitHub
