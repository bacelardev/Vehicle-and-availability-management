Protótipo da Interface — Sistema de Locação de Veículos

1. Objetivo

Este documento apresenta o protótipo visual da interface do sistema de gerenciamento e locação de veículos, desenvolvido utilizando o Figma.

2. Ferramenta utilizada

Figma: ferramenta utilizada para elaborar as telas, organizar os elementos visuais e representar a navegação entre as funcionalidades do sistema.

3. Telas desenvolvidas

O protótipo contempla as seguintes interfaces:

Login: tela de autenticação dos usuários.

Home do Cliente: página inicial com acesso às funcionalidades disponíveis.

Reserva de Veículos: interface para consultar e solicitar a reserva de veículos.

Manutenção: interface relacionada ao gerenciamento das manutenções dos veículos.

4. Acesso ao protótipo

Link do projeto no Figma: https://www.figma.com/design/RxGm5yLz3CE3W43DQO5Och/Projeto-ED?node-id=5-2&p=f&t=Pg9UInYgCPPIdawt-0

5. Observações

O protótipo representa a proposta visual do sistema e serve como referência para o desenvolvimento das interfaces e funcionalidades da aplicação.
