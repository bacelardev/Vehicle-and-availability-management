# Escopo do Projeto

O sistema tem como objetivo controlar os veículos pertencentes à frota
de uma locadora.

## Funcionalidades

1. Cadastrar veículos.
2. Impedir cadastro de placas duplicadas.
3. Classificar veículos por categoria.
4. Registrar capacidade máxima de passageiros.
5. Registrar quilometragem.
6. Controlar status do veículo.
7. Pesquisar veículos.
8. Listar veículos disponíveis por período.
9. Impedir reservas sobrepostas.
10. Bloquear veículos para manutenção.
11. Impedir reservas durante manutenção.
12. Ordenar veículos.
13. Consultar histórico de aluguéis.
14. Registrar quilometragem de retirada e devolução.
15. Calcular quilômetros percorridos.
16. Identificar veículos que necessitam manutenção.
