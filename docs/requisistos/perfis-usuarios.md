# Perfis de Usuário

## Administrador

Responsável por:

- cadastrar veículos;
- editar informações;
- cadastrar períodos de manutenção;
- consultar histórico;
- visualizar veículos que necessitam manutenção.

## Atendente

Responsável por:

- consultar veículos;
- verificar disponibilidade;
- realizar reservas;
- registrar retirada;
- registrar devolução;
- registrar quilometragem.
